# Asset Credits

All visual elements in this prototype use only built-in browser emoji and CSS styling.
No third-party graphical assets are currently included.

## Planned / Recommended Sources

If you extend the prototype with graphical assets, use:

- **Kenney.nl** (https://kenney.nl) — UI packs, icons, health bars — CC0 license
- **itch.io** — search "card game UI" or "fantasy RPG cards" — check individual licenses
- **The Noun Project** (https://thenounproject.com) — math icons — CC BY or paid license
- **OpenGameArt** (https://opengameart.org) — sprites, backgrounds — various CC licenses

Place downloaded assets here in `public/assets/` and update this file with the specific
asset name, author, source URL, and license for each.
