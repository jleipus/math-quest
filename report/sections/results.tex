\section{Results}

% Briefly describe your results/solution.

The outcome is a fully functional prototype that demonstrates the core interaction loop: solving math challenges to unlock cards, receiving guidance when stuck, and progressing through combat encounters. The prototype includes several complementary features like a CI/CD pipepline to automate deployment and user persistence by logging in with Googe account, allowing users to retain their profiles for repeat sessions.

Upon evaluation with the teacher, we learned that the \enquote{MiniGuide} strategy produces pedagogically sound guidance, and that generated question content and difficulty matches that which is present in the standard curriculum.

From the student demo session, unfortunately we did not receive sufficient survey responses to derive informative conclusions, but saw sufficient engagement with the system to draw insights from.
