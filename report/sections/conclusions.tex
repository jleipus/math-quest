\section{Conclusions and Future Work}

% Briefly summarise your results and what the next steps would be if/when you or others would continue with the project.

Our aim for this project was to investigate how Active Learning in primary mathematics education can be systematically supported through a responsible, interactive AI system. We successfully implemented a RAG-based gamefied system that provides adaptive scaffolding, and attempted to evaluate it on the target demograpic.
While we were unable to collect sufficient data to properly answer all the research questions we had raised, strong positive indications were observed. 

Further work with this system would explore options for expanding the content base used as RAG context. Additionally, the system could be adapted to support a wider variety of question formats (e.g. images, non-numeric answers). With these improvements, it would be interesting to see whether the system could be expanded to target not only 4--6 grades, but elder students as well.
