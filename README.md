## Frontend API Base URL

The frontend reads the API base URL from `NEXT_PUBLIC_API_BASE_URL`.

Create `frontend/.env.local` from `frontend/.env.example` and set:

`NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8000/api/v1`
